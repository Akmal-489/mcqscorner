Active Voice

Subject does the action.

- Ahmed eats an apple

Passive Voice

Subject receives the action.

- An apple is eaten by Ahmed

Formula

Active: Sub + Verb + Obj

Passive: Obj + H.V + Past Participle + by + Sub

Tenses Conversion Rules:

1: Present Simple

- Active: Sub + V1 + O

- Passive: Obj + is/are/am + V3 + by + Sub

e.g; He writes a letter =>> A letter is written by him

2: Present Continuous

- Active: Sub + is/are/am + V1 + ing + Obj

- Passive: Obj + is/are/am + being + V3 + by + Sub

e.g; He is singing a song =>> A song being sung by him

3: Present Perfect

- Active: Sub + has/have + V3 + O

- Passive: Obj + has/have + been + V3 + by + Sub

e.g; They have completed the work =>> The work has been completed by them

4: Past Simple

- Active: Sub + V2 + O

- Passive: Obj + was/were + V3 + by + Sub

e.g; The teacher taught English =>> English was taught by the teacher

5: Past Continuous

- Active: Sub + was/were + V1 + ing + O

- Passive: Obj + was/were + being + V3 + by + Sub

e.g; She was cooking dinner =>> Dinner was being cooked by her

6: Past Perfect

- Active: Sub + had + V3 + O

- Passive: Obj + had + been + V3 + by + Sub

e.g; He had solved the problem =>> The problem had been solved by him

7: Future Simple

- Active: Sub + will/shall + V1 + O

- Passive: Obj + will/shall + be + V3 + by + Sub

e.g; They will finish the project =>> The project will be finish by them

8: Future Continuous

- No Passive

9: Future Perfect

- Active: Sub + will/shall + have + V3 + O

- Passive: Obj + will/shall + have + been + V3 + by + Sub

e.g; He will have completed assignment =>> The assignment will have been completed by him
