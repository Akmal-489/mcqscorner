Computer Construction MCQs

1: There are ______ types of software development processes.

Select the correct option

  • Three
  • Five
  • Four
  • Two

Explanation: There are four main types of software development processes (models) commonly recognized in software engineering.

  1. Waterfall Model
  2. Incremental Model
  3. Spiral Model
  4. Agile Model

2: Every ______ of the Iterative Model finishes in an exact and fixed period that is callel iteration.

Select the correct option

  • Phase
  • Release
  • Step
  • Stage

Explanation: In the Iterative Model, each phase or (cycle) of development is completed in a fixed & predefined time period, known as an iteration.

Each iteration includes activities like planning, design, coding, & testing, producing a working version of the software that is improved in subsequent iterations.

3: Following are the major activities in software construction except.

Select the correct option

  • Project Planning

  • Debugging
  • Coding

Explanation: The major activities in software construction include:

  1. Coding
  2. Testing
  3. Debugging

These are all directly related to building & verifying the software.

Project Planning, however is part of software project management not software construction.
