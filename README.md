MCQs Website: This project is a simple educational website that provides Multiple Choice Questions (MCQs) for practice. This website includes MCQs from different subjects to help students prepare for exams.
Subjects Included: Islamic Studies, Mathematics, English and Computer Science.
Technologies Used: HTML & CSS.
Features: Simple & clean interface, Subject-wise MCQ pages.
Project Purpose: This website is created for learning & practice purposes & to help students test their knowledge in different subjects.
